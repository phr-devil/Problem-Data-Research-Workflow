# PD-RW 专题导航（INDEX_ONLY）

仅用于**任务类型尚不明确**时定位文件；优先使用根目录 [AGENTS.md](../AGENTS.md) 的直接路由。索引不制定科研规则、权限或附加关卡，不要求每次任务先读本文件。

| 当前目标 | 按需入口 | 权威内容 |
|---|---|---|
| 新题、数据、算法、实验、科学确认 | [research](research/README.md) | [WORKFLOW.md](../WORKFLOW.md) 与相关真实科研证据 |
| 论文蓝图、Word 结构、写作、期刊 | [paper](paper/README.md) | 论文规划/写作门禁专题 |
| 已获用户明确授权的图件设计/修改 | [figures](figures/README.md) | [FIGURE_POLICY.md](../FIGURE_POLICY.md) |
| 权限边界或规则冲突 | [policies](../policies/README.md) | [WORKFLOW.md](../WORKFLOW.md) |

读取规则：确定具体任务 → **只读相应的权威专题文件和原项目来源** → 执行授权内工作 → 最小交接；已知路径不再额外读取索引。维护说明见 [STRUCTURE.md](../docs/STRUCTURE.md)。
