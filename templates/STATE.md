# PD-RW｜最小续做 STATE（按需字段，不是填写表）

现有STATE、RUNS、CLAIMS、manifest优先**复用原路径**；只更新本轮变化和下一步所需字段，其他不复制、不填空占位。原始日志/图片/代码留在原处；未运行NOT_RUN，证据不足UNKNOWN。

## 常驻索引（仅变化时更新）
- WORKFLOW: PD-RW v1.7.1（仅用户明确选择；旧项目兼容）
- USER_SCOPE: <本轮用户研究范围或「方向不限」；SCOPE_UNSPECIFIED不继承旧课题>
- AREA_DATA: <当前大问题及选择来源；未选WAITING_FOR_USER_SELECTION>
- ACTIVE_TASK: <当前TASK_ID/合法K/部署前信息/协议；可UNDECIDED>
- AUTH/BUDGET: <实际下载/安装/CPU或GPU拟合/确认等许可及上限；否则UNAUTHORIZED>
- HOLDOUT: <UNTOUCHED/CONTAMINATED/UNKNOWN/NOT_APPLICABLE及适配任务证据>
- BEST_VALID_RUN: <有效Run ID＋原始指标/配置/代码路径；NONE>
- NEXT: <唯一最有价值的合法行动＋POS/NEG/INVALID及成本>
- PATH_MAP: <现有RUNS/CLAIMS/代码/数据索引，不复述文件内容>

## 专题索引（当前涉及才添加，其他省略）
- SEARCH_TRACE: <查询来源/日期/覆盖缺口；SEARCH_PARTIAL>
- DIRECTION_CARD: <宽方向/变化轴/独立真值假设>
- DATA_PORTFOLIO: <可评价主库D1、按需外部/备用、SEALED_CONFIRM角色；必要时EXTERNAL_EVIDENCE_GAP>
- DATA_CHOICE: <PREFERRED及选择证据指针>
- PRE_DOWNLOAD_PLAN: <必需D1/外部库；官方版本/文件清单/大小/许可/存储与下载授权>
- DOWNLOAD_READY_NOTICE: <无下载授权时给出的可执行下载/保存/续传指引；WAITING_FOR_DOWNLOAD_AUTH>
- DATA_MANIFEST: <逐库expected/actual文件与字节/有则哈希/读入冒烟/真实路径/缺失项；NOT_RUN>
- DATA_READINESS: <逐库required_now与DATA_ACQUIRED_VERIFIED/PARTIAL_DATA/WAITING_FOR_DATA/WAITING_FOR_DOWNLOAD_AUTH/NOT_APPLICABLE；是否SCOPE_REDUCED；旧FULL_VERIFIED需复核映射>
- DATA_INSIGHTS: <关键DATA_INSIGHT_CARD路径或NO_RELIABLE_INSIGHT_YET>
- OBSERVATIONS: <OBSERVED/HYPOTHESIZED/PROXY_ONLY及原始来源>
- TASK_DISCOVERY: <PRIMARY_TASK/必要RESERVE_TASK/MINIMUM_PROBE>
- TASK_CANDIDATES: <候选选择史链接，不复制>
- PORTFOLIO_PIVOT_MAP: <真正不同失败前提的备选>
- TASK_LADDER: <可选L0–L3不同信息条件及切换证据；NOT_APPLICABLE>
- IMPLEMENTATION: <需要编码时才记TaskSpec/evaluator指纹、接口/保护/定向测试；未知标UNKNOWN>
- ALGORITHM_HYPOTHESIS: <仅重大机制：ERROR_PATTERN/MECHANISM_LEVER/STRONG_SIMPLE_ALTERNATIVE/DISCRIMINATING_SIGNATURE/PROBE>
- EXPERIMENT_BRANCH: <BRANCH_ID/parent_run/失败前提/差异性Probe及竞争解释/可复用资产/NEXT_DISTINCT_PROBE/累计GPU/Token/人工成本>
- NEXT_ACTION_OWNER: <AGENT_DECIDABLE/STRONG_RECOMMENDATION/USER_DECISION_REQUIRED；原始授权/项目级决定指针；遵守NEXT_ACTION_POLICY.md>
- NEXT_ACTION_FORMAT: <NEXT_AGENT_INSTRUCTION 仅当权限已覆盖；否则 RECOMMENDATION+OPTIONS+USER_CHOICE_NEEDED；本轮无需下一行动则NO_NEXT_ACTION>
- PUBLICATION_TARGET: <JCR Q2+投稿潜力，优先Q1；不要求实际录用，参见Q2_PUBLICATION_GOAL.md>
- Q2_PREFLIGHT: <可选 Q2_PACKET_JSON 结构校验路径/READY_FOR_HUMAN_SCIENTIFIC_AND_JCR_REVIEW/INCOMPLETE；不是科学成功认证>
- Q2_COMPETITIVENESS: <Q2_POTENTIAL_SUPPORTED / Q2_UPGRADE_POSSIBLE / Q2_UNCERTAIN / BELOW_Q2_TARGET；须引用科学与期刊证据，非CLI状态>
- Q2_VENUE_EVIDENCE: <期刊/JCR年度/学科类别/分区/索引/来源与日期/已发表同类文章；未核UNKNOWN>
- PUBLICATION_GOAL_RESULT: <PROJECT_SUCCESS_Q2_POTENTIAL / IN_PROGRESS / FAILED_Q2_TARGET；无真实证据不得宣称成功；录用另记>
- PAPER_PATH: <PERFORMANCE_FLOOR/PAPER_PATH_CANDIDATE/SCIENCE_UPGRADE及证据指针；科学评价并非写作授权>
- RESEARCH_SUMMARY_REF: <成果总结路径/版本；否则 NONE>
- SUMMARY_USER_REVIEW: <PENDING / REVIEWED + 可核查用户原始确认消息；缺失默认 PENDING>
- MANUSCRIPT_WRITE_AUTH: <LOCKED / APPROVED + 用户针对本项目/主张的明确写作指令来源；默认 LOCKED；参见 WRITING_GATE.md>
- SCIENCE_UPGRADE_AUDIT: <可选：Run/最近邻差额/竞争解释/区别性预测/成本/授权/UPGRADE_PILOT|EVIDENCE_ONLY|KEEP_ORIGINAL|UNKNOWN；非写作授权>
- HIGH_VALUE_RESEARCH_DESIGN: <按需：重要问题/具名近邻知识差额/科学辨识力与混杂/竞争性假设/不同预言/最低决定性测试；UNKNOWN保留；见HIGH_VALUE_RESEARCH_DESIGN.md>
- SCIENTIFIC_VALUE: <不同于具名近邻的新能力/规律；VALUE_UNVERIFIED>
- CLAIM_EVIDENCE_MAP: <能力/机制/规律候选、最强替代、Run和工件指针、最近复盘、待补证据/确认资格>
- CLAIM_CANDIDATE: <一句Claim或UNVERIFIED>

区分RUN/MECHANISM、TASK、AREA_DATA、EVIDENCE、AUTH及PAPER_READINESS；单次负Pilot不能项目级STOP。每轮不得回显完整STATE。

已启用机器索引的项目参见 [core/README.md](../core/README.md)；原始授权仍以用户消息为准，不能从STATE的字段推断许可。现有纯Markdown项目不强制迁移。
